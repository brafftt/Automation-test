# Newsletter Templates

Templates prontos baseados na MoneyMaker Newsletter.

## Template 1: Educação + Método

**Estrutura**: Problema → Solução → Método → Conclusão

### Assunto
```
ð° [Emoji] [Benefício rápido - máx 8 palavras]

Exemplos:
ð° A method simples que me impede de ficar pobre
ð° Como estruturar o teu dinheiro em 5 contas
```

### Corpo

```
[Nome],

[GANCHO PESSOAL]
Durante muito tempo, achei que...
Até que recebi uma lição de [livro/pessoa/experiência]...

[PROBLEMA IDENTIFICADO]
Antes de aplicar isto, o meu dinheiro...
E no final do mês, sobrava...

[TRANSIÇÃO]
Hoje, utilizo um método simples, mas extremamente eficaz...

[SOLUÇÃO DETALHADA]
Como funciona:

1️⃣ [Passo 1]
   • Explicação
   • Benefício

2️⃣ [Passo 2]
   • Explicação
   • Benefício

3️⃣ [Passo 3]
   • Explicação
   • Benefício

[VALIDAÇÃO]
Porque este sistema funciona:
✅ Garante que...
✅ Cria...
✅ Evita...

[CTA]
E tu, já usas um sistema parecido ou tens tudo [situação]?
Responde a este email.

[ASSINATURA]
[Nome]
```

## Template 2: Comparação Reveladora

**Estrutura**: Mito → Realidade → Números → Conclusão

### Assunto
```
ð° O número mágico (e não, não é 1 milhão)
ð¸ Como comprei um apartamento por 15€
⚠️ O erro que quase me arruinou
```

### Corpo

```
[Nome],

[SETUP]
Se achas que [mito comum], tenho [emoção] para ti.

[PERSONAGEM 1]
ðµ O [Nome] - O sortudo
• Idade: [X]
• Situação: [descrição]
• Vantagens: ✅ [lista]
ð° Poupança necessária: [número] (só [detalhes])

[PERSONAGEM 2]
ðµ O [Nome] - O azarado
• Idade: [X]
• Situação: [descrição]
• Desvantagens: ❌ [lista]
ð° Poupança necessária: [número muito maior]
   • Entrada: [X]
   • Impostos: [X]
   • Custos: [X]

[CHOQUE NUMÉRICO]
⚖️ Conclusão:
Se tens [condição], aproveita.
Se já passaste... prepara a carteira.

O [Nome], mais velho um mês, precisa de ± [diferença] a mais.

[CTA]
❓ E tu, és [Nome] ou [Nome]?
Responde aqui no email.

[CHAMADA AOS SOCIAL]
No meu [rede social] tens muito conteúdo como este.
Segue-me: [link]

[ASSINATURA]
[Nome]
```

✅ [Ação 2] - [Resultado]
✅ [Ação 3] - [Resultado]

## Template 4: Provocação + Reflexão

**Estrutura**: Afirmação Polêmica → Explicação → Desafio

### Assunto
```
⚠️ Se tens menos de 36 anos, lê isto
ð» Porque deixei de acreditar em [crença comum]
```

### Corpo

```
[Nome],

[PROVOCAÇÃO]
[Afirmação forte/controversa]

[EXPLICAÇÃO DO PORQUÊ]
Porquê? Porque...

Pensa nisto:
• [Ponto 1]
• [Ponto 2]
• [Ponto 3]

[VALIDAÇÃO COM EXPERIÊNCIA]
Eu percebi isto quando [história pessoal]...

[ALTERNATIVA PROPOSTA]
O que faz mais sentido é...

✅ Em vez de [coisa errada]
✅ Faz [coisa certa]

[REFLEXÃO FINAL]
Se [situação], então [conclusão].

Porque o [conceito] não cresce nas árvores,
mas pode crescer nas tuas mãos.

[CTA PESSOAL]
❓ [Pergunta reflexiva]
Responde a este email.

[ASSINATURA]
[Nome]
```

## Template 5: Roadmap / Estratégia

**Estrutura**: Objetivo → Caminho → Passos → Timeline

### Assunto
```
ð¡ O plano para fazer [objetivo] sem esperar [tempo longo]
ð O passo a passo para [resultado]
```

### Corpo

```
[Nome],

[VISÃO]
Porque raio haverias de esperar [tempo longo] para [objetivo]...
Quando [teu método] podes fazê-lo em [tempo curto]?

[COMPARAÇÃO]
ð MÉTODO TRADICIONAL
• Retorno: [X]
• Tempo: [X]
• Esforço: [X]
Total: [X] anos

ð MÉTODO INTELIGENTE (Teu)
• Retorno: [X]
• Tempo: [X]
• Esforço: [X]
Total: [X] anos

RESULTADO: [diferença significativa]

[PASSO A PASSO]
1️⃣ [Passo]
   → [Resultado]

2️⃣ [Passo]
   → [Resultado]

3️⃣ [Passo]
   → [Resultado]

[VALIDAÇÃO]
E se usares estratégias como:
✔️ [Estratégia 1]
✔️ [Estratégia 2]
✔️ [Estratégia 3]

...então estás a jogar noutro campeonato.

[CONCLUSÃO]
Resultado final?
[Tempo curto] em vez de [tempo longo].

[CTA]
❓ Faz mais sentido [opção A] ou [opção B]?

Se estás farto de [situação] e queres [solução],
[Chamada à ação específica]

[ASSINATURA]
[Nome]
```

## Elementos Transversais

### Gancho Inicial (sempre usar)
```
[Nome],
[Afirmação direta/Pergunta/Constatação]
```

### Validação (sempre incluir)
```
✅ [Benefício 1]
✅ [Benefício 2]
✅ [Benefício 3]
```

### Call-to-Action (tipos)
```
❓ Pergunta aberta ("E tu, o que achas?")
ð Link/Inscrição ("Inscreve-te aqui")
ð Reflexão ("Qual é o teu objetivo?")
ð Ação ("Responde a este email")
```

### Fechamento
```
[Frase motivacional/reflexão final]

[Nome]
```

## Dicas de Implementação

✅ **Para cada email, preenche UM template**
✅ **Adapta os números ao teu caso**
✅ **Mantém o tom pessoal e direto**
✅ **Sempre de semana a semana**
✅ **Sempre com CTA claro**
