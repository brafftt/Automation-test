# Glossário

Termos e conceitos utilizados no projeto.

## A

**Access Token**  
Credencial que permite acesso à API. No Meta, usado para autenticar requisições.

**Ad (Anúncio)**  
Conteúdo de publicidade no Meta. Pode ser imagem, vídeo ou carousel.

**AdSet (Conjunto de Anúncios)**  
Grupo de anúncios com a mesma segmentação, budget e cronograma.

**API**  
Application Programming Interface. Interface para comunicação entre sistemas.

## B

**Bot**  
Aplicação automatizada. No Slack, é um app que envia mensagens.

**Block Kit**  
Linguagem de formatação do Slack para criar mensagens ricas.

**Business Account**  
Conta de negócios no Meta para gerenciar campanhas de publicidade.

**Business Manager**  
Plataforma do Meta para gerenciar múltiplas contas e campanhas.

## C

**Campaign (Campanha)**  
Objetivo de publicidade maior que agrupa múltiplos AdSets.

**CPC (Cost Per Click)**  
Custo médio por clique. Fórmula: Spend / Clicks.

**CPM (Cost Per Mille)**  
Custo por mil impressões. Fórmula: (Spend / Impressions) * 1000.

**CTR (Click-Through Rate)**  
Taxa de clique. Percentual de pessoas que clicaram no anúncio.  
Fórmula: (Clicks / Impressions) * 100.

## D

**Data Flow (Fluxo de Dados)**  
Caminho que os dados seguem pelo sistema.

**Dashboard**  
Interface visual para visualizar dados.

## E

**Email Campaign (Campanha de Email)**  
Envio de emails para lista de contatos no GHL.

**Endpoint**  
URL específica de uma API para executar uma ação.

## G

**GHL (GoHighLevel)**  
Plataforma de marketing automation para agendar e enviar emails.

**Graph API**  
API do Meta para acessar dados de campanhas e anúncios.

## H

**Header (Cabeçalho)**  
Informação adicional em requisição HTTP. Ex: Authorization.

**HTML**  
HyperText Markup Language. Linguagem para estruturar emails e páginas.

## I

**Insight (Métrica)**  
Dado de performance de uma campanha. Ex: impressões, cliques, conversões.

**Impressions (Impressões)**  
Número de vezes que um anúncio foi exibido.

## J

**Jinja2**  
Motor de templates Python para gerar HTML dinamicamente.

**JSON**  
Formato de dados para comunicação entre sistemas. Usa chave-valor.

## L

**List (Lista)**  
Coleção de contatos no GHL para receber emails.

## M

**Meta**  
Empresa proprietária do Facebook e Instagram.

**Newsletter**  
Email informativo enviado periodicamente para lista de contatos.

## N

**Notification (Notificação)**  
Mensagem enviada para alertar sobre um evento.

## O

**OAuth**  
Protocolo de autenticação que permite acesso seguro a APIs.

## P

**Payload**  
Dados enviados em uma requisição HTTP.

**Performance**  
Medida de sucesso de uma campanha (ROAS, CTR, etc).

**Permission (Permissão)**  
Autorização para acessar dados específicos via API.

## Q

**Query Parameter**  
Parâmetro passado na URL. Ex: `?limit=10&offset=20`.

## R

**Reach (Alcance)**  
Número de pessoas únicas alcançadas por um anúncio.

**Rate Limit**  
Limite de requisições que uma API permite em um período.

**Retry**  
Tentativa novamente após falha.

**ROAS (Return on Ad Spend)**  
Retorno sobre gastos em publicidade.  
Fórmula: Revenue / Ad Spend.

## S

**Slack**  
Plataforma de comunicação para equipes.

**Status Code**  
Código de resposta HTTP (200, 404, 500, etc).

## T

**Template**  
Estrutura pré-definida para gerar conteúdo (email, mensagem).

**Threshold**  
Limiar ou valor mínimo para algo. Ex: performance > 0.7.

**Token**  
Credencial de autenticação para acessar APIs.

## U

**URL**  
Endereço web de um endpoint.

**User ID**  
Identificador único de um usuário.

## V

**Validation (Validação)**  
Verificação se dados estão corretos antes de processar.

## W

**Webhook**  
URL que recebe dados em tempo real quando algo acontece.

## X

**X-Header**  
Headers customizados. Ex: `X-RateLimit-Remaining`.

## Z

**ZIP (Compressão)**  
Formato comprimido de arquivos.
